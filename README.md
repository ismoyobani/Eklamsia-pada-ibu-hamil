# Eklampsia pada Ibu Hamil — Maternal Learning Studio

Media pembelajaran digital untuk mahasiswa keperawatan mengenai eklampsia pada ibu hamil dan postpartum.

## Isi materi
- Ikhtisar dan tujuan pembelajaran
- Konsep dasar, definisi, faktor risiko, dan waktu kejadian
- Patofisiologi dan komplikasi maternal-fetal
- Tanda bahaya, manifestasi klinis, dan pemeriksaan
- Prinsip penanganan kegawatdaruratan
- Fokus pengkajian dan asuhan keperawatan
- Komunikasi SBAR dan studi kasus simulasi
- Referensi WHO, NICE, dan sumber klinis

## Teknologi
- HTML, CSS, dan JavaScript murni
- Tidak memerlukan proses build atau dependensi
- Responsif untuk desktop dan perangkat seluler
- Tidak menggunakan database karena konten bersifat edukatif dan tidak menyimpan data pengguna/pasien

## Menjalankan secara lokal
Buka `index.html` melalui browser.

## Deploy ke Vercel
Hubungkan repository GitHub ini ke Vercel. Framework preset: **Other**. Build command dikosongkan; output directory menggunakan root project.

## Catatan keselamatan
Konten ini merupakan bahan pembelajaran, bukan alat diagnosis atau panduan tindakan mandiri. Kejang pada ibu hamil atau postpartum adalah kegawatdaruratan medis. Penanganan, pemberian obat, pemantauan, dan keputusan persalinan wajib mengikuti pedoman klinis terbaru, kewenangan tenaga kesehatan, serta SOP fasilitas kesehatan.
